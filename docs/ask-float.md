# 答案卡浮層：失敗點清單（T1125034901）

答案會變成使用者本人的輸入 ⇒ 有疑問一律不送。送出只有一條路：`ask.html` → `SphereEmbed.askAction` → 原本的 `answer`／`permit` → `BoardActions` → `AskQueue.claim`。

疊法：衛星是主視窗裡的 subview（不是獨立視窗），所以浮層也是主視窗的 subview，放在最上面；命中測試另外保證浮層優先。不設系統置頂、不另開視窗 ⇒ 全螢幕、多螢幕、最小化都跟著主視窗。登入畫面開著時藏起來。

## 網頁免重開（T1125194238）

`scripts/swap_app.py ask <ask.html>` 只換答案卡網頁；主程式有改就照舊 `build_app.sh`＋重開（執行檔不同，執行中的不會熱換）。目前載入的版本：`~/Library/Application Support/Orbit42/ask-page.json`（hash＝ask.html 的 SHA-256、waiting＝驗過在等、note＝最近發生什麼）。不要在已裝的 App 裡原地改檔重簽。

已知、沒動：同一個 session 同時有待答題和權限框時，球體資料只給待答題（權限框等題目答完才出現），這是原本就有的行為。
