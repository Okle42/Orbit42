# 答案卡浮層：失敗點清單（T1125034901）

答案會變成使用者本人的輸入 ⇒ 有疑問一律不送。送出只有一條路：`ask.html` → `SphereEmbed.askAction` → 原本的 `answer`／`permit` → `BoardActions` → `AskQueue.claim`。

疊法：衛星是主視窗裡的 subview（不是獨立視窗），所以浮層也是主視窗的 subview，放在最上面；命中測試另外保證浮層優先。不設系統置頂、不另開視窗 ⇒ 全螢幕、多螢幕、最小化都跟著主視窗。登入畫面開著時藏起來。

| # | 可能怎麼錯 | 擋法 |
|---|---|---|
| 1 | 卡片跳出來時正在終端機打 1 或 Enter ⇒ 被當成作答 | 跳出、換題、展開都不拿焦點；沒被滑鼠點過的浮層不收鍵盤（原生 `acceptsFirstResponder`＋`performKeyEquivalent` 都擋） |
| 2 | 點過卡片、焦點回終端機後按數字 | 失焦立刻解除（原生 resign ＋ 網頁 blur） |
| 3 | 送出後按太多下，下一題被答 | 送出、換題就解除鍵盤；要再點一次卡片 |
| 4 | 換題瞬間滑鼠點到新題 | 換題、展開、選項變動後 0.5 秒內的點擊不算；按下和放開要同一題同一顆按鈕，按下那刻也要過了 0.5 秒 |
| 5 | 中文組字的 Enter／數字送出 | `isComposing`、keyCode 229、組字結束後 150ms 內都不算 |
| 6 | 按住不放（repeat）連送 | repeat 不算 |
| 7 | 新題插進來換掉正在看的 | 題目照到達順序排、固定看原本那題；新題只加數字 |
| 8 | 看到一半題目在別處答掉／撤回 | 顯示「已經答掉或收回」、按鈕全停用，1.5 秒後才換下一題（正在打字不自動換） |
| 9 | 同一 session 換了一題，補充草稿跑到新題 | 草稿照題目 id 存，不照 session |
| 10 | 復原的 3 秒內題目沒了、或改了選項 | 送出前再比一次題目內容，不一樣就不送並講明 |
| 11 | 同題連按兩次 | 送出就離開清單；原生 `AskQueue.claim` 再擋 |
| 12 | 「沒確認到」的題又被按一次 | 顯示「請到終端機看」，按鈕停用（原生也回 busy） |
| 13 | 網頁重新載入時替他送出 | 重新載入＝不送，題目還在可以再按 |
| 14 | 權限框換了一張，按到新的那張 | 一定帶 permitId；原生比對不符、或框已關就不動作 |
| 15 | 用鍵盤 Space／Enter 觸發「有焦點的按鈕」 | 按鈕不拿焦點；detail 為 0 的 click 不算 |
| 16 | 點標題要跳終端機，卻變成作答 | 標題、問題只跳，不含作答動作；拖動超過 4px 不算點 |
| 17 | 拖出視窗找不回來 | 每次擺放都夾在視窗內；視窗變小自動拉回，變大回原位 |
| 18 | 縮成一條後擋到終端機輸入框 | 縮條避開每顆開著的衛星下緣 96pt；四個角挑一個 |
| 19 | 卡片蓋住衛星，點擊卻穿到底下 | 命中測試先問浮層；點浮層不會把底下的衛星提上來 |
| 20 | 補充框打字中卡片被重畫，聽寫斷掉 | 同一題永遠不換輸入框；打字中智能體不開口（沿用原規則） |
